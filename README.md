# Maggie Anne Co.

Website and brand assets for Maggie Anne Co., a small creative studio offering thoughtfully designed websites and creative services.

**Tagline:** Thoughtfully designed. Personally crafted.

## Project structure

- `assets/brand/` — logos and brand identity files
- `assets/images/` — website photography and image assets
- `assets/icons/` — decorative icons and illustrations
- `index.html` — website content
- `style.css` — website styling
- `script.js` — website interactions
